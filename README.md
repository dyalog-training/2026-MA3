# 2026-MA3
These are the pre-requisites materials for the Dyalog '26 workshop MA3: Concurrent Programming in Dyalog.

Clone this repository or [download as a .zip](https://github.com/dyalog-training/2026-MA3/archive/refs/heads/main.zip) before the workshop.

## Overview

This workshop covers basic usage and design considerations around concurrency in Dyalog APL.

1. Introduction: Key Concepts
1. Parallelism Performance
1. Thread Safety

## Learning Objectives

- Understand the difference between green threads (&) and "real" threads (¤/∥)
- Know how to assess performance trade-offs when considering concurrency implementation
- Know when threads switch in running Dyalog programs
- Know how locking mechanisms can be used to safely manage shared resources in multithreaded programs
